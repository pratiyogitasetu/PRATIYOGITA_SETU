# 🗑️ DELETED FILES REFERENCE — Pratiyogita Gyan
## Deployment Cleanup — August 17, 2026

This file documents every file and directory that was deleted during deployment cleanup.
Each item includes: **what it was**, **what it was used for**, **its size**, and **how to recreate it** if needed in the future.

---

## 📁 DELETED DIRECTORIES

---

### 1. `backend/venv/` — Python Virtual Environment
- **Size**: ~1,018 MB (1 GB)
- **What it was**: A full Python virtual environment containing all installed pip packages (Flask, Groq, Pinecone, possibly torch, sentence-transformers, etc.)
- **What it was used for**: Running the backend Flask app locally during development. The `venv` folder holds all Python dependencies isolated from your system Python.
- **Why deleted**: Deployment platforms (Render, Railway, Heroku) create their own virtual environment from `requirements.txt`. This folder should NEVER be deployed — it's massive and platform-specific.
- **How to recreate**:
  ```bash
  cd backend
  python -m venv venv
  venv\Scripts\activate        # Windows
  # source venv/bin/activate   # Linux/Mac
  pip install -r requirements.txt
  ```

---

### 2. `.venv/` (Root) — Root-Level Python Virtual Environment
- **Size**: ~54 MB
- **What it was**: Another Python virtual environment at the project root (separate from `backend/venv/`).
- **What it was used for**: Possibly used for running training scripts or as an alternate dev environment.
- **Why deleted**: Same reason as above — never needed in deployment. Redundant with `backend/venv/`.
- **How to recreate**:
  ```bash
  cd pratiyogita_gyan
  python -m venv .venv
  .venv\Scripts\activate
  pip install -r backend/requirements.txt
  ```

---

### 3. `node_modules/` — Node.js Dependencies
- **Size**: ~238 MB
- **What it was**: Contains all npm packages for the React/Vite frontend (React, React Router, Tailwind CSS, Vite, ESLint, etc.)
- **What it was used for**: Required for running `npm run dev` (local development) and `npm run build` (production build). Every package listed in `package.json` gets installed here.
- **Why deleted**: Vercel and other platforms run `npm install` automatically during deployment. This folder is rebuilt from `package.json` + `package-lock.json`.
- **How to recreate**:
  ```bash
  cd pratiyogita_gyan
  npm install
  ```

---

### 4. `dist/` — Frontend Production Build Output
- **Size**: ~6 MB
- **What it was**: The output of `npm run build` — compiled, minified HTML/CSS/JS ready for production.
- **Contents included**: `index.html`, `assets/` (bundled JS/CSS), copies of SVG/PNG files from `public/`, `sw.js`, `offline.html`
- **What it was used for**: This is what gets served to users in production. Vercel serves these files.
- **Why deleted**: Vercel runs `npm run build` on every deploy and generates a fresh `dist/`. The local copy was stale.
- **How to recreate**:
  ```bash
  npm run build
  ```

---

### 5. `backend/__pycache__/` — Python Bytecache
- **Size**: ~0.2 MB
- **What it was**: Python's compiled bytecode cache (`.pyc` files) for faster module loading.
- **What it was used for**: Automatically generated by Python when importing modules. Speeds up subsequent imports.
- **Why deleted**: Regenerated automatically every time Python runs. Never needed in version control or deployment.
- **How to recreate**: Happens automatically when you run `python app.py`.

### 7. `backend/test_terminal.py`
- **Size**: 4,454 bytes (113 lines)
- **What it was**: A comprehensive terminal test script for the Nemotron-3-Embed-1B embedding model and PYQ search system.
- **What it was used for**: Running end-to-end tests from the command line to verify:
  1. System initialization works
  2. MCQ embedding model loads correctly
  3. Raw embedding generation speed (latency tests)
  4. `/api/pyq/search` endpoint returns correct results
  5. `/api/search` main chat endpoint works
  6. `/api/pyq/filters` endpoint responds
  7. `/api/pyq/random` endpoint responds
- **Why deleted**: Development/debugging tool not needed in production deployment.
- **Full source code for future reference**:

```python
#!/usr/bin/env python3
import os
import sys
import time
import json

# Ensure UTF-8 output on Windows consoles
if hasattr(sys.stdout, 'reconfigure'):
    sys.stdout.reconfigure(encoding='utf-8', errors='replace')
if hasattr(sys.stderr, 'reconfigure'):
    sys.stderr.reconfigure(encoding='utf-8', errors='replace')

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))

from app import app, initialize_search_system, search_components, encode_query

print("=" * 70)
print("RUNNING COMPREHENSIVE TERMINAL TEST FOR NEMOTRON-3-EMBED-1B")
print("=" * 70)

# 1. Initialize system
print("\n[Step 1] Initializing Search System...")
t0 = time.time()
initialize_search_system()
init_time = time.time() - t0
print(f"Initialization completed in {init_time:.2f}s")
print(f"MCQ Model in use: {type(search_components.get('mcq_model')).__name__}")
print(f"MCQ Backend name: {search_components.get('mcq_backend')}")
print(f"MCQ Index in Pinecone: {os.getenv('MCQ_INDEX_NAME')}")
print(f"NCERT Search Disabled: {os.getenv('DISABLE_NCERT_SEARCH') == '1'}")

# 2. Test raw embedding latency
print("\n[Step 2] Testing Raw Embedding Generation Speed...")
mcq_model = search_components.get("mcq_model")
for test_prompt in ["Article 21 Indian Constitution", "Hybridization in crop varieties", "Mughal painting under Akbar"]:
    t_start = time.time()
    vec = encode_query(mcq_model, test_prompt)
    lat = (time.time() - t_start) * 1000
    print(f"\"{test_prompt}\" -> {len(vec)}d vector generated in {lat:.1f}ms")

# 3. Test PYQ Search API Endpoint
print("\n[Step 3] Testing /api/pyq/search Endpoint (Retrieval from pyq-nemotron)...")
client = app.test_client()
search_queries = [
    "Akbar court painting books",
    "Fundamental Rights Constitution",
    "crossing genetically dissimilar plants hybridization"
]

for query in search_queries:
    t_start = time.time()
    resp = client.post("/api/pyq/search", json={
        "query": query,
        "similarity_threshold": 0.01,
        "limit": 3
    })
    duration = (time.time() - t_start) * 1000
    if resp.status_code == 200:
        data = resp.get_json()
        total = data.get("total", len(data.get("questions", [])))
        print(f"\nQuery: '{query}'")
        print(f"Status: {resp.status_code} OK | Retrieved: {total} matches in {duration:.1f}ms")
        questions = data.get("questions", [])
        for i, q in enumerate(questions[:2], 1):
            score = q.get("score") or q.get("similarity_score") or "N/A"
            q_text = q.get("question", "")
            print(f"Match #{i} (Score: {score}): {q_text[:90]}...")
    else:
        print(f"Query failed with status {resp.status_code}: {resp.get_data(as_text=True)}")

# 4. Test Main /api/search (Chatbot endpoint - PYQ only, NCERT blocked)
print("\n[Step 4] Testing Main /api/search (Chat Search - PYQ only mode)...")
t_start = time.time()
resp_search = client.post("/api/search", json={
    "query": "Which book was not illustrated in Akbar's court?",
    "n_results": 3,
    "mcq_threshold": 0.01,
    "mcq_limit": 3
})
chat_duration = (time.time() - t_start) * 1000
if resp_search.status_code == 200:
    data = resp_search.get_json()
    print(f"Status: {resp_search.status_code} OK in {chat_duration:.1f}ms")
    print(f"NCERT Sources returned: {len(data.get('sources', []))} (Expected: 0 - blocked)")
    print(f"PYQ MCQ Matches returned: {len(data.get('mcq_results', []))}")
    print(f"AI Answer: {data.get('rag_response', '')[:160]}...")
else:
    print(f"Search failed with status {resp_search.status_code}: {resp_search.get_data(as_text=True)}")

# 5. Test Filters Endpoint
print("\n[Step 5] Testing /api/pyq/filters Endpoint...")
t_start = time.time()
r_filters = client.get("/api/pyq/filters")
f_lat = (time.time() - t_start) * 1000
print(f"Status: {r_filters.status_code} OK in {f_lat:.1f}ms")
if r_filters.is_json:
    f_data = r_filters.get_json()
    print(f"Available filter categories: {list(f_data.keys())}")

# 6. Test Random Questions Endpoint
print("\n[Step 6] Testing /api/pyq/random Endpoint...")
t_start = time.time()
r_rand = client.post("/api/pyq/random", json={"count": 2})
rand_lat = (time.time() - t_start) * 1000
print(f"Status: {r_rand.status_code} OK in {rand_lat:.1f}ms")
if r_rand.is_json:
    rand_data = r_rand.get_json()
    print(f"Random questions returned: {len(rand_data.get('questions', []))}")

print("\n" + "=" * 70)
print("ALL TERMINAL TESTS COMPLETED SUCCESSFULLY!")
print("=" * 70)
```
